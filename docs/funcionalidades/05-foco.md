# 05 · Modos de foco

| Modo | Jogos | Redes sociais |
|---|---|---|
| Desligado | Cota | Cota → parcial |
| **Parcial** | Bloqueados | Só consumo bloqueado (Reels, Shorts…); criar/publicar/mensagens liberados |
| **Total** | Bloqueados | Bloqueadas por completo |

- O usuário pode **iniciar** um foco com duração (25 min, 1 h, 2 h, 4 h). Só o admin pode **encerrar antes** ou reduzir o nível — também é *append-only*.
- O foco aparece na Now Bar: "Foco total · até 18:00".
